# Slides

此目录用于课程展示材料。

当前项目：毕赤酵母摇瓶发酵生产 hLF，从零开始（无历史数据）。之前 HMO 发酵罐阶段的内容已作废，不再适用。

课程 PDF 要求提交 5-10 页 PPT PDF，或 10-12 分钟 demo video。建议结构：

1. Problem：零历史数据起步，摇瓶每轮 15~20 个样本、2~5 轮的约束下如何优化 hLF `yield_g_per_l`
2. Data：摇瓶 run-level 数据模板与回填流程；当前尚无真实实验数据，首轮结果将是第一批训练信号
3. Method：两轮设计。Round 1 是灵活方案构建器——基线重复（估计纯误差）、单变量法(OFAT，连续变量测试水平可自定义)、联合探索(LHS) 三个模块独立开关组合；Round 2 用基线重复的纯误差方差做显著性检验（t 分布置信区间）筛出活跃变量(K)，再做响应面(CCD)设计和两个独立 GP（产量、OD600）的约束贝叶斯优化
4. Results：首轮/后续轮次建议、变量探索范围覆盖情况、Round 2 效应量排序与显著性阈值线解读
5. Explainability：置信区间宽度如实反映基线重复数（默认 3 次，df=2）带来的信息量、活跃变量数(K)如何决定哪些变量进入响应面细化、约束 BO 的可行性过滤逻辑（产量优先，OD600 不过低即可）
6. Limitations and Future Work：零数据起步的不确定性、少量基线重复导致的置信区间宽度、摇瓶与发酵罐工艺差异、轮次弹性调整规则（稳定减 1 轮/不稳定加 1~2 轮）、Round 2 响应面回归的正式统计推断（系数标准误/失拟检验）留待 CCD 实测数据回填之后
