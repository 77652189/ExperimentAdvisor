# ADR-0007：Round 1 变量集合与 CCD 边界设计规则

## 元数据

- 决策发生时间（推断自会话记录）：2026-05-28
- 本记录补记时间：2026-07-31

## 背景

Round 1 设计早期迭代中，曾考虑把补料/葡萄糖起始时间（`glucose_start_time_h`）作为独立变量，也曾用参数的全局最小/最大值作为 DOE 水平的默认取法。后续发现两者都有问题：该时间变量对当前工艺意义有限、只会增加不必要的维度；全局 min/max 作为水平会让设计点脱离实际可操作、有历史支撑的取值范围。

Round 2 的 CCD 设计还有一个独立问题：如果某变量的最优值恰好卡在硬边界附近（例如 `volume_ml` 卡在上限 75），naive 地按 `±step` 生成轴点会超出 `CONTINUOUS_BOUNDS`；简单裁剪超界的一侧会让设计退化为不对称（一侧点数多、一侧少甚至重合于中心）。

## 决策

- 彻底移除 `glucose_start_time_h` 变量，不在模板、UI、DOE 变量选择、推荐结果、反馈分析中出现。
- DOE/OFAT 水平不默认取变量的全局最小/最大值，改用协议/历史数据给出的具体水平（`OFAT_LEVELS`）。
- `generate_ccd` 在检测到某变量最优值贴近硬边界时，将整个采样带整体向内平移，而不是单侧裁剪导致设计不对称。

## 后果

`tests/test_round2_design.py::test_generate_ccd_shifts_band_inward_at_a_hard_boundary` 是边界平移规则的常设回归守卫。全仓库不应再出现 `glucose_start_time_h`；如果以后要恢复该变量，需要新开 ADR 说明恢复的理由。

## 取代关系

无。
