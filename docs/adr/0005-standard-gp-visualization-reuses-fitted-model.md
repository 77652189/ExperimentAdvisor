# ADR-0005：标准 GP-BO 的可视化复用推荐阶段拟合的同一 GP 对象

## 元数据

- 决策发生时间（推断自会话记录）：2026-05-26
- 本记录补记时间：2026-07-31

## 背景

标准 GP-BO（qNEI）生成推荐时会拟合一个 `SingleTaskGP`。后验切片图、偏依赖图（PDP）等可视化如果各自重新拟合一个 GP，会导致"推荐用的模型"和"图上展示的模型"不是同一个对象——用户看到的解释可能和实际生成推荐时用的模型对不上。

## 决策

`recommend_standard_bo`/`recommend_standard_bo_ei` 拟合出的 GP 对象通过 `comparison["model_info"]["fitted_standard_bo_gp"]` 向下传递；`_standard_gp_plot`、`_gp_pdp`（现均在 `App/pages_legacy_ecoli.py`）只接收并使用这个已拟合对象作画图输入，不在函数内部重新调用拟合逻辑或重新实例化 `SingleTaskGP`。

## 后果

可视化和推荐结果保证是"同一个模型"的两个视角，不会出现"图上曲线和推荐值互相矛盾"的情况。如果以后要给可视化换一个不同的、更简单的模型（例如只为画图配一个轻量 GP），需要新开 ADR 说明为什么"同一模型"这条不再成立。

## 取代关系

无。
