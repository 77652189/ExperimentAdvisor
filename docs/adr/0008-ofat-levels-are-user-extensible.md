# ADR-0008：Round 1 单变量法(OFAT)水平允许用户运行时新增自定义值

## 元数据

- 决策发生时间（推断自会话记录）：2026-07-28
- 本记录补记时间：2026-07-31

## 背景

OFAT 各变量的推荐测试水平最初来自协议/历史数据（`OFAT_LEVELS`），但固定水平无法覆盖研发人员临时想测的取值，也不允许勾掉不想测的水平。

## 决策

Round 1 设计构建器的 UI 里，OFAT 推荐水平只是预填、可勾掉移除，并提供专门的输入框 + 按钮让用户在生成设计前新增自定义水平；`generate_round1_design` 的 `ofat_levels` 参数本身接受任意 `dict[str, list[float]]`，不锁定为模块级默认值 `OFAT_LEVELS`。

## 后果

协议给的水平是起点不是上限，实际测试范围由研发人员在生成设计前的这一次交互决定。

## 取代关系

无。
