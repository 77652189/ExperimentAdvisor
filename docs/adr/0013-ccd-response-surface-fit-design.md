# ADR-0013：CCD响应面拟合——全二次OLS模型、中心点估纯误差、最优点只搜已测范围

## 元数据

- 决策发生时间：2026-08-11（本次会话）
- 本记录补记时间：2026-08-11

## 背景

`generate_ccd` 一直只负责生成 CCD 的设计点，从没有代码真正去拟合结果、给出响应面方程或预测最优点——CCD 方法本身最核心的产出（正式的响应面模型）在这次之前一直缺失。新增 `fit_ccd_response_surface` 时，有几处需要明确选定做法而不是随手实现：

1. 模型该拟合到什么阶数、要不要包含交互项。
2. 失拟检验的"纯误差"该从哪里来。
3. 找预测最优点时，搜索范围该多大——原始 `CONTINUOUS_BOUNDS`，还是 CCD 实际测过的范围。

## 决策

1. **模型形式**：完整二次模型——截距 + 每个活跃变量的一次项 + 二次项 + 两两交互项，用普通最小二乘（`numpy.linalg.lstsq`）拟合。这是 CCD/RSM 的标准分析模型，跟 `generate_ccd` 的角点(测交互)/轴点(测二次项)/中心点(测纯误差)结构逐项对应，不是任意选的模型。
2. **失拟检验的纯误差来源**：只用中心点的重复测量（`generate_ccd` 默认放 3-5 个中心点，正是为这个检验存在），不使用技术重复或其他任何重复来源。用标准的失拟 F 检验（`SS_lack_of_fit`/`SS_pure_error`）。当设计里没有重复点（比如 K=1 默认设计的残差自由度正好被纯误差自由度用完）时，明确返回 `lack_of_fit=None`，不是猜一个"没有失拟"或报错。
3. **每个系数的显著性**：额外用 OLS 系数协方差矩阵（`MSE * (X'X)^-1`）算每个模型项自己的标准误/t检验/p值——这是和"整体模型失拟检验"独立的另一层信息（后者检验"模型形式对不对"，前者检验"这一项本身是不是噪声"），两者都保留、不能互相替代。
4. **最优点搜索范围**：网格搜索限制在每个活跃变量在这批 CCD 数据里的实际 min/max，不是 `CONTINUOUS_BOUNDS` 定义的原始 Round 1 边界。拟合出来的二次曲面只在有数据支撑的区域内可信，搜到边界外等于用一条拟合曲线做外推，而外推的可信度这个模型完全没有校验过。

## 后果

- `ResponseSurfaceFit` 同时暴露 `r_squared`、`lack_of_fit`、`coefficient_significance`、`optimum`/`predicted_optimum` 四类信息，UI 层（`_pichia_round2_results_analysis_section`）分别展示，不能只看 R² 就下结论。
- `evaluate_response_surface`/`response_surface_grid` 复用同一份已拟合系数做预测（残差诊断图、等高线图都不重新拟合），保证"图上看到的"和"表格里报告的系数"永远是同一个模型。
- 如果某个活跃变量的 CCD 测试范围很窄（比如被硬边界推得只剩很小一段），预测最优点也只能落在这段窄范围内——这不是 bug，是如实反映"这批数据只能负责这么大的推断范围"。

## 验证

`tests/test_round2_design.py` 里 `test_fit_ccd_response_surface_*`、`test_evaluate_response_surface_*`、`test_response_surface_grid_*` 系列（共 9 条），全部用能手算验证的合成数据构造——包括一个精确二次函数验证 R²=1、一个真实交互系数为 0 验证显著性检验能正确不误报、一个单点注入 50 倍偏差验证失拟检验能正确抓出来、一个真实最优点落在原始边界外验证搜索范围不会外推出去。
